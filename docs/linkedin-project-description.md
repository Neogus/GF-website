# LinkedIn Project Description

## GF Inspecciones y Ensayos — Corporate Website

**Role:** Full-Stack Developer & Designer
**Tech Stack:** Next.js 16 · TypeScript · Tailwind CSS 4 · Framer Motion · Cloudflare Pages

### Overview

Designed and developed a complete corporate website for an industrial inspection and non-destructive testing (NDT) company based in Buenos Aires, Argentina. The site serves as the company's primary digital presence, targeting B2B clients in the energy, petrochemical, pharmaceutical, construction, and industrial manufacturing sectors.

### Key Achievements

- **Built 10+ SEO-optimized service pages** with unique metadata, JSON-LD structured data (schema.org), and OpenGraph tags — enabling each service to rank independently on Google (e.g., `/servicios/ensayos-no-destructivos`, `/servicios/ultrasonido`)
- **Implemented bilingual support (ES/EN)** with a custom React Context-based i18n system and runtime language toggle, serving both local and international clients
- **Designed a professional B2B interface** with scroll-triggered animations, responsive layouts (mobile-first), and a cohesive brand identity derived from the company's logo colors
- **Developed a server-side contact form** using Next.js API routes and Nodemailer for reliable email delivery with HTML templates and input sanitization
- **Configured for Cloudflare Pages deployment** using the OpenNext adapter for edge-rendered performance with global CDN distribution
- **Implemented comprehensive SEO architecture:** dynamic sitemap.xml, robots.txt, Google Business Profile-compatible Organization schema with geo-coordinates, and inter-page cross-linking strategy

### Technical Highlights

- Tailwind CSS v4 with custom theme tokens (design system)
- Framer Motion for performant scroll-based animations
- Static pre-rendering (SSG) for sub-second page loads
- Fully typed with TypeScript strict mode
- Clean component architecture with reusable service page template

### Impact

Delivered a production-ready website that positions the company as a trusted, professional partner in the industrial inspection market, with a strong foundation for organic search visibility across all service offerings.
