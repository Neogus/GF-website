## Option A: Technical Focus

🚀 Just shipped a new project!

Built a complete corporate website for an industrial inspection company using:

⚡ Next.js 16 + TypeScript
🎨 Tailwind CSS 4 + Framer Motion
🌍 Bilingual (Spanish/English)
🔍 10 individual SEO-optimized service pages
📧 Server-side contact form with email delivery
☁️ Deployed on Cloudflare Pages (edge-rendered)

The site features JSON-LD structured data for Google Business Profile, dynamic sitemap, and a fully responsive design targeting B2B clients in the energy and industrial sectors.

One of the most interesting challenges was architecting the SEO strategy — each service (NDT, welding inspection, pressure vessels, corrosion assessment, etc.) has its own page with unique metadata and schema markup, so they can rank independently on search engines.

Tech decisions that made a difference:
→ Tailwind v4's CSS-first configuration for a clean design system
→ OpenNext adapter for full Next.js support on Cloudflare's edge network
→ Reusable ServicePage component pattern for consistent service pages
→ Custom i18n context with runtime language switching (no page reload)
